# 건물계약서 서식 참고 항목

건물관리 메뉴의 입력 항목과 분리하여, 추후 건물계약서 서식을 만들 때 참고할 목록이다.
이 문서의 항목은 현재 건물관리 화면에서 직접 입력하거나 월정산 계산값으로 사용하지 않는다.

## 공용비·시설 부담 조건

- 공용전기 부담 주체
- 공용수도 부담 주체
- 정화조 부담 주체
- E/L 유지관리 부담 주체
- 소방관리 부담 주체
- 전기안전관리 부담 주체
- 보험관리 부담 주체
- 인터넷 부담 주체
- 유선 부담 주체

## 별도 메뉴 자료를 계약서에 참고 표시

- 수리비등록의 공용 건물관리비 내역
- 수리비등록의 공용전기·수도·정화조·시설 관련 내역
- 공용수리비 내역
- 중개수수료 발생 내역

## 계약서 기본·특약 참고

- 관리형태와 수금통장 주체
- 보장입금 여부
- 보장 범위: 건물 전체 / 층별
- 보장금액 방식: 정해진 금액 / 층별 계약서 월세 합계
- 건물 전체 보장금액 또는 층별 보장금액
- 계약기간
- 공실·미납·퇴실 관련 특약
- 관리비·공용비·시설비 부담 특약

## 별도 계산 화면에서 처리하는 항목

다음 항목은 계약서 참고자료로 연결할 수 있지만 건물관리 입력값으로 저장하지 않는다.

- 입실월·퇴실월 선불/후불 계산
- 계약일 미달·초과 일수 계산
- 퇴실정산 확정금액 연결
- 세입자 실입금·대체금·미수
- 최초보증금과 현재 계약 보증금 비교
- 보증금대체
- 당월지급액·당월청구액
- 퇴실자·공실·신규입주 행 표시
